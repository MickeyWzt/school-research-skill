# Contributing to School Research Skill

Thanks for improving this school-research skill. The project is meant for source-backed education research, so the most valuable contributions improve evidence quality, report structure, or PDF readability.

## Good First Contributions

- Improve research checklists for admissions, tuition, financial aid, student life, outcomes, or international applicants.
- Add output templates for common school types.
- Improve the PDF renderer or sample report data.
- Add examples that show verified, inferred, and unclear claims.
- Document how to handle conflicting official sources.
- Improve Chinese-language output guidance while preserving official English names.

## Evidence Rules

Contributions should preserve the skill's research standard:

- Prefer official school sources before external commentary.
- Label claims as `verified`, `inferred`, or `unclear` when appropriate.
- Do not silently omit missing categories in a deep profile.
- Keep source logs concrete enough for a reader to audit.
- Be explicit about dates, applicant categories, campuses, and entry cycles.

## Before Opening a Pull Request

1. Explain which research or reporting behavior changes.
2. Include a small example if the output format changes.
3. Keep templates practical and readable.
4. Avoid adding claims that cannot be tied to sources.
5. If you change PDF rendering, mention how you checked the output.

## Reporting Issues

When reporting an issue, include:

- The school or program being researched.
- Applicant category and entry cycle if relevant.
- The output mode used, such as quick profile, deep report, checklist, or PDF.
- Any source category that was missing, stale, or confusing.
- The command used for PDF rendering if the issue is renderer-related.

## Scope

This skill helps structure research. It should not present uncertain admissions, visa, financial aid, or legal information as guaranteed advice.
