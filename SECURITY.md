# Security Policy

## Scope

This repository contains a research workflow and PDF renderer for school due-diligence reports. Security-sensitive reports may include unsafe file handling in the renderer, dependency issues, or output behavior that could expose private applicant information.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities that expose private applicant data, local files, or sensitive research notes.

Report privately through GitHub's security reporting flow if available, or contact the maintainer through the GitHub profile.

Include:

- A short description of the issue.
- Affected file, script, or template.
- Steps to reproduce with non-sensitive sample data.
- Whether the issue affects PDF rendering, source logs, or generated reports.

## Data Safety

Do not include private student records, passport or visa details, financial records, school portal credentials, personal contact information, or unpublished application materials in public issues or pull requests.

## Advice Boundary

The skill structures research and evidence review. It should not present uncertain admissions, visa, financial aid, or legal information as guaranteed advice.

## Supported Versions

Security fixes are applied to the `main` branch.
