# Roadmap

This roadmap keeps School Research Skill focused on evidence quality, readable reports, and careful decision support.

## Current Focus

- Prioritize official school sources.
- Keep source logs auditable.
- Make deep reports explicit about missing or unclear evidence.
- Produce readable PDF reports from structured findings.

## Near-Term Improvements

- Add more sample report JSON files for different school types.
- Add renderer checks for required report sections.
- Improve templates for admissions fit, cost, risks, and timelines.
- Add examples for conflicting official sources.
- Add clearer guidance for international applicant research.

## Longer-Term Ideas

- More PDF layout themes.
- A compact one-page decision brief mode.
- A comparison workflow that still preserves single-school evidence quality.
- Better structured JSON schema documentation.
- Optional spreadsheet export for application planning.

## Non-Goals

- Presenting uncertain admissions facts as guaranteed advice.
- Replacing official school guidance.
- Storing private applicant records in public examples.
- Treating external rankings as stronger evidence than official sources.
