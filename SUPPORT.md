# Support

School Research Skill helps structure source-backed research on one school or academic program. Useful support requests should make the school, applicant category, and output mode clear.

## Before Opening an Issue

Check these first:

1. The school, campus, program, applicant category, and entry cycle are specific.
2. Official source categories were attempted before external commentary.
3. Missing source categories are explicitly marked rather than silently omitted.
4. Claims are labeled as `verified`, `inferred`, or `unclear` when appropriate.
5. Private applicant information is not included in public issues.

## Where to Ask

- Use a bug report issue for PDF rendering problems, unclear templates, source-labeling problems, or broken examples.
- Use a feature request issue for new report sections, school types, output formats, or research standards.
- Use the security policy for private applicant data, local file exposure, or unsafe renderer behavior.

## Useful Details

When asking for help, include:

- School or program name.
- Applicant category and entry cycle.
- Output mode, such as quick profile, deep report, checklist, risk register, or PDF.
- Source category that was missing, stale, or confusing.
- PDF render command if the issue is renderer-related.

## Scope

The skill structures research and report writing. It does not guarantee admissions, scholarship, visa, financial aid, or legal outcomes.
